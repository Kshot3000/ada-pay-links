Pay-with-ADA links for small businesses. No backend. No custodian.

Enter a receive address, an amount, and a memo. This page builds a shareable link and QR code, lets a payer send ADA from Lace, Eternl, or Nami with the memo on-chain, and checks payment status against a public Koios indexer. Testnet first — this project is in testing.

    How it works
    
        
      
          
    1. Link. The desk builds a hosted pay-page URL (?network=…&address=…&amount=…&memo=…) and a CIP-13 URI (web+cardano:<address>?amount=…) for wallets that support it.
      2. 
          
    2. QR. The pay-page URL is rendered as a QR code locally in your browser (vendored MIT QR library; nothing is uploaded).
      3. 
          
    3. Pay. The payer connects a CIP-30 wallet. The transaction sends ADA to your address and writes the memo as CIP-20 metadata (label 674). No funds ever pass through this site.
      4. 
          
    4. Verify. Status is checked through public Koios by address + memo, then the received ADA is compared to the requested amount. A transaction link is shown when a match is found.
      5. 
        
    
        
    No server, no sign-up, no custody, no secrets in this repo. Always double-check the receive address and the network in your wallet before paying. This software is in testing and is not audited.
